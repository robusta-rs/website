# Robusta Website

The documentation site for [Robusta](https://github.com/robusta-rs/robusta), built with [VitePress](https://vitepress.dev).

### Contributing

Install [vite-plus](https://viteplus.dev) if you don't have it already.

Then run:

```sh
vp install
vp run dev
```

### Fonts

The site serves Fraunces, JetBrains Mono, and Inter, all under the SIL Open Font License 1.1.
Their license texts are published from `public/licenses/`.
